# 予定通知は会話のモデルと音声で本日の残りの予定を案内し、重複より取りこぼしを選ぶ

予定の通知時刻には、現在から本日中に開始する予定をすべて案内する。最初の塾だけを知らせると、あとに塾がある家族が自分の予定はないと思い、準備をしないおそれがあるためである。予定名の人名に自然な敬称を補う既存の予定確認を保つため、固定文ではなく会話のモデルと音声を共用する。自動生成の入力は実際のユーザー発言と区別する。最小化やトレイ格納中の通知は見送り、画面を戻したときには通知できなかった旨だけを表示する。再生と保存は一つの処理として確定できないため、通知を始めた事実を先に保存し、異常終了などで結果が分からなくても自動では再送しない。家庭内で同じ案内を重ねることを防ぐほうを優先する。

## 見送った案

- 固定の文をTTSで読む。予定名にある人名への敬称など、既存の会話で得られていた自然な読み替えが失われる。
- 今日の全予定を毎回案内する。すでに始まった予定まで繰り返し聞かせる必要はない。
- 通知のきっかけとなった予定だけを案内する。あとに予定のある家族が準備する機会を失う。
- 不確かな通知を自動再送する。異常終了直前に聞こえていた案内を繰り返す可能性がある。
