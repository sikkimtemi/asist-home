# カレンダーの定期取得は、予定の音声通知を有効にしたときだけ行う

通常の画面や会話では、予定を使うときにGoogle Calendar APIを読む。asist-homeでは家庭の予定を事前に音声で知らせるため、音声通知を有効にした場合だけ定期取得も行う。予定の通知時刻は取得の間隔と分けて管理する。開発中は変更をすぐ検証できる60秒、運用時は家庭で必要な更新頻度に合わせて30分を使う。Googleからのpush通知は、公開の受け口と端末への接続を維持するサーバーが必要になるため使わない。

## 見送った案

- 音声通知でも、予定を画面や会話で使うときだけ読む。誰も操作していないときに、追加された家族の予定を知ることができない。
- 全期間の予定を同期して手元に写す。家庭で直近の予定を知らせる用途には、期間を指定した取得で足りる。
