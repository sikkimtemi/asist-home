ASIST は、OpenAI の「Sign in with ChatGPT」を使って、ChatGPT の Plus か Pro のプランで会話できます。API キーを作る必要はなく、会話の分はプランの使用量に含まれます。Mac でも Windows でも手順は同じです。

## ログインすると何が起きるか

- ASIST は、ChatGPT のアカウントに「ASIST」という名前のアプリとして登録されます。OpenAI は、ログインのときに、アカウントの名前、メールアドレス、プロフィールの画像を ASIST に渡します。ASIST が保存するのは、メールアドレスと、ログインを続けるためのトークンだけです。
- プランの利用を許可すると、ASIST での会話がプランの使用量から使われます。
- ASIST は、ChatGPT での会話や、ChatGPT の記憶を見られません。プランの利用の許可は、それらを見る許可を含みません。
- ASIST には OpenAI のサーバーはなく、ログインも会話も、このコンピュータと OpenAI のあいだで行います。

## 使えるプラン

プランを使えるのは、ChatGPT の Plus と Pro だけです。ほかのプランのアカウントでログインすると、会話のときに「この ChatGPT のアカウントのプランは、ASIST では使えません。Plus か Pro のプランが必要です。」と出ます。その場合は、ほかの提供元の API キーを使います。

<Steps>

1. **ChatGPT でログインする**

   初回セットアップの「会話のモデル」で「ChatGPT」を選ぶか、設定の「API キー」の「ChatGPT」の行で「ChatGPT で続ける」を押します。

   ![「ChatGPT で続ける」のボタンがある、API キーのページの ChatGPT の行](/screens/ja/chatgpt-sign-in.webp)

2. **ブラウザで ASIST に許可する**

   ブラウザで ChatGPT のログインの画面が開きます。使うアカウントでログインし、ASIST が受け取る情報と、「Use your ChatGPT plan」(プランの利用)の許可を確かめてから進みます。プランの利用を許可しないと、ASIST では会話できません。

   「ChatGPT でログインしました。このタブを閉じて ASIST に戻ってください。」と出たら、タブを閉じて ASIST に戻ります。ブラウザでのログインは、5 分以内に終えます。

3. **プランを使うことの案内を閉じる**

   初めてログインしたときだけ、ASIST での会話がプランの使用量に含まれることを伝える案内が出ます。読んだら閉じます。

4. **会話のモデルに ChatGPT を選ぶ**

   初回セットアップでログインしたときは、会話のモデルが GPT-6.1 Terra、つなぎの一言のモデルが GPT-6 Luna になります。設定からログインしたときは、設定の「会話」で、提供元に「ChatGPT」を選びます。保存済みのモデル選択は、アプリを更新しても変わりません。

   ![ログインして、ChatGPT のプランを使っている API キーのページの ChatGPT の行](/screens/ja/chatgpt-signed-in.webp)

</Steps>

## 使用量と上限

- 会話、つなぎの一言、履歴の要約が、プランの使用量に含まれます。OpenAI はこれを、プランに含まれる ChatGPT Work と Codex の使用量として数えます。
- ASIST が使った分は、[ChatGPT の設定の使用量](https://chatgpt.com/settings/usage)で見られます。ここで、ASIST が使ってよい週の割合を決めることもできます。ASIST の設定の「会話」と「API の料金」にある「使用量を管理する」からも開けます。
- Plus には 5 時間ごとの使用量の上限があり、ChatGPT 自身やほかのアプリと同じ枠を使います。Pro には 5 時間ごとの上限はありません。
- 上限に達すると、ASIST は「ChatGPT の使用量の上限に達しました。」と伝えて止まります。API キーを保存していても、そちらに切り替えて会話を続けることはしません。上限が戻るのを待つか、ChatGPT の設定で使用量を確かめます。
- 設定の「API の料金」には、ChatGPT の分はトークンの数だけが出て、金額は出ません。

## API キーで使うときとの違い

- 返事の始まりが、同じモデルを API キーで使うときより 1 秒ほど遅くなります。
- 選べるモデルは、GPT-6 Luna、GPT-6 Sol、GPT-6 Astra、GPT-6.1 Terra、GPT-6.1 Sol と、GPT-5.6 Luna、GPT-5.6 Terra、GPT-5.6 Sol です。利用できるかは、ログインしたアカウントのプランとモデルの提供状況によります。使えないモデルを選ぶと、保存の前に「ログインしている ChatGPT のアカウントでは使えません」と出ます。
- Web 検索は使えます。

## ログアウトと切断

- 設定の「API キー」の「ChatGPT」の行で「ログアウト」を押すと、ASIST は OpenAI にログインの取り消しを伝え、保存したトークンを消します。アカウントのアドレスは、次にログインするときのために残ります。
- 別のアカウントに替えるときは、「別のアカウントで続ける」を押します。前のアカウントのログインは、OpenAI 側でも取り消します。
- ChatGPT の側からも切断できます。ChatGPT の設定のセキュリティの項目で、ChatGPT でログインしたアプリの一覧を開き、ASIST を選んで切断します(英語の画面では Settings → Security and login → Sign in with ChatGPT)。ASIST でログアウトしただけでは、この一覧から ASIST は消えません。

## ログインの保存と、送るもの

ログインのトークンは、このコンピュータの中に暗号化して保存します。暗号化の鍵は、Mac ではキーチェーンの鍵、Windows では Windows のユーザーに結び付いた鍵(DPAPI)です。Agent のジョブなど、ASIST が起動するほかのプログラムには渡しません。

会話は、あなたの ChatGPT のアカウントで OpenAI に送ります。送るものは、API キーで使うときと同じです([外へ送るもの](/docs/privacy/external/))。プランで送った会話を OpenAI がどう扱うかは、OpenAI のヘルプに書かれていないので、[OpenAI のプライバシーポリシー](https://openai.com/policies/privacy-policy/)と、ChatGPT の設定のデータの管理の項目を確かめてください。

## うまくいかないとき

- ブラウザを閉じてしまったときは、もう一度「ChatGPT で続ける」を押します。前のログインは取り消され、新しいログインが始まります。
- 「ChatGPT のプランを使う許可がありませんでした」と出たときは、もう一度ログインして、プランの利用を許可します。
- 「前回とは別の ChatGPT のアカウントが選ばれたため、ログインをやめました」と出たときは、前回のアカウントを選び直すか、「別のアカウントで続ける」を押します。
- 「ChatGPT のログインが切れました」と出たときは、もう一度ログインします。ログインは、30 日のあいだ一度も使わないと切れます。ChatGPT の側で切断したときも同じです。
- 「保存した ChatGPT のログインを読めません」と出たときは、「ログアウト」を押すか、もう一度ログインします。
