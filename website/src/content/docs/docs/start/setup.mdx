最初に開くと、9 つの画面を順に進みます。話し方に要らない画面は飛ばします。各画面の下に、次にやることが 1 行で出ます。

<Steps>

1. **言語を選ぶ**

   11 の言語から 1 つ選びます。最初に選ばれているのはシステムの言語です。選んだものが、画面の言語、会話の言語、地域の 3 つの初期値になり、ここから先の画面はその言語で出ます。3 つは、あとから設定で別々に変えられます。設定の「キャラクター」にある ASIST の人柄の文章も、会話の言語のものになります。日本語なら日本語、ほかの言語なら英語の文章です。書き換えていなければ、あとで会話の言語を変えたときも、それに合わせて変わります。

   ![言語を選ぶ画面](/screens/ja/setup-1-language.webp)

2. **使う前に知っておくことを読む**

   答えが間違うことがあること、変更は承認してから行うこと、API の料金は提供元から請求されること、会話は選んだ提供元に送られることの 4 つが出ます。読んだら「4つの点を読んで理解しました」にチェックを入れて進みます。詳しくは[安全に使うために](/docs/privacy/safety/)にあります。この画面ができる前にセットアップを終えていた人には、次に開いたときに同じ内容が一度だけ出ます。

   ![使う前に知っておくことの画面](/screens/ja/setup-safety.webp)

3. **会話のモデルの API キーを入れる**

   提供元を選んで API キーを入れ、「検証して保存」を押します。キーは実際に問い合わせて確かめ、使えると分かったときだけ保存します。会話には、その提供元の標準のモデルを使い、つなぎの一言には、軽くて速いモデルを使います。どちらも、あとから設定で変えられます。

   「ChatGPT」を選ぶと、API キーの欄の代わりに「ChatGPT で続ける」が出ます。ブラウザで ChatGPT にログインすると、Plus か Pro のプランで会話できます。くわしくは [ChatGPT のプランで使う](/docs/start/chatgpt/)にあります。

   ![API キーを検証して保存した画面](/screens/ja/setup-2-model.webp)

4. **話し方を選ぶ**

   「声で話す」「音声モデルとリアルタイムで話す」「文字で打ち、返事は声で聞く」「文字だけで使う」から選びます。

   「音声モデルとリアルタイムで話す」では、Gemini Live が聞き取りと読み上げを受け持つので、聞き取りと読み上げの画面は飛ばします。Gemini Live には Google の API キーが要ります。前の画面で Google のキーを検証していれば、もう一度入れる必要はありません。前に保存したキーや環境変数のキーがあれば、これを選んだときにそのキーを検証するので、入れ直す必要はありません。キーがなければ、この画面でキーを入れて「検証して保存」を押します。声は Google の標準のもので、あとから設定で変えられます。料金は[声のエンジン](/docs/settings/voice-engine/)にあります。

   ![話し方で「声で話す」を選んだ画面](/screens/ja/setup-3-speaking.webp)

5. **聞き取りのモデルを準備する**(「声で話す」のとき)

   Mac ではメモリが 16GB 以上なら Qwen3-ASR 1.7B を、それより少なければ Qwen3-ASR 0.6B を勧めます。Windows では、単体の GPU のメモリが 6GB 以上なら 1.7B を、それより少なければ 0.6B を勧めます。「モデルを準備する」を押すと、モデル(1.7B は約 2.2GB、0.6B は約 0.8GB)を取得して、このコンピュータの GPU で動かします。「詳細」では、ほかのモデルも選べます。一覧には、会話の言語を聞き取れるモデルだけが出ます([声のエンジン](/docs/settings/voice-engine/))。ブラウザの中で動く Whisper も選べます。Windows の内蔵 GPU でも聞き取りを使えます。自動は Qwen3-ASR 0.6B で、日本語なら「詳細」から Haas-ja-v1.0(約 0.66GB)も選べます。使える Vulkan GPU が無いときは理由が出るので、ブラウザの中で動く Whisper を選びます。

   Windows では、新しいバージョンの ASIST を初めて起動したときと、GPU のドライバーを更新したあとの最初の起動で、ドライバーが GPU で動かすためのプログラムを作ります。そのときだけ、準備にいつもより時間がかかります。

   ![おすすめのモデルの準備が終わった画面](/screens/ja/setup-4-listening.webp)

6. **読み上げを選ぶ**(「声で話す」か「文字で打ち、返事は声で聞く」のとき)

   会話の言語を話せるものだけが出ます。日本語なら、Mac では Irodori-TTS、Qwen3-TTS、「macOS の音声合成」、VOICEVOX、AivisSpeech、Windows では Irodori-TTS、Qwen3-TTS、「Windows の音声合成」、VOICEVOX、AivisSpeech です。Irodori-TTS と Qwen3-TTS は、メモリが 16GB 以上の Mac と、単体の GPU のメモリが 8GB 以上の Windows で出ます。最初に選ばれているのは、日本語なら Irodori-TTS、ほかの言語なら Qwen3-TTS で、Qwen3-TTS が話せないヒンディー語とインドネシア語では OS の音声合成です。この 2 つが出ないコンピュータでは、日本語なら VOICEVOX、ほかの言語なら OS の音声合成が選ばれています。

   Irodori-TTS は日本語だけを読みます。モデル(約 1.9GB)を取得して、このコンピュータの GPU で動かします。声は 3 つあり、あとから設定の「声」の「読み上げ」にある「声」で変えられます。声ごとのカードの ▶ で同梱の見本を聞けるので、モデルを取得する前でも聞き比べられます。Qwen3-TTS の 9 つの声も同じところで選べて、見本は会話の言語で読んだものです。Qwen3-TTS は 0.6B のモデル(約 1.2GB)を取得します。メモリが 24GB 以上の Mac と、GPU のメモリが 10GB 以上の Windows では、あとから設定の「声」の「読み上げ」にある「モデル」で 1.7B(約 2.3GB)に変えられます。変えたときは、その下に出る「準備する」で新しいモデルを準備します。OS の音声合成を選んだときは、その言語の声が入っているかを調べ、無ければシステム設定か Windows の設定のどこで足すかを案内します。

   ![読み上げの準備ができた画面](/screens/ja/setup-5-speech.webp)

7. **マイクを許可する**(「声で話す」か「音声モデルとリアルタイムで話す」のとき)

   「マイクを検証する」を押すと、実際に音を受け取れるかを確かめます。Mac では、その前に macOS が許可を求めるので「許可」を押します。Windows は許可を求めません。

   ![マイクを確かめた画面](/screens/ja/setup-6-microphone.webp)

   <Aside type="tip">
   許可しなかったときは、この画面からシステム設定か Windows の設定を開くか、文字で打つ使い方に切り替えられます。あとから許可するには、[マイクの許可](/docs/start/microphone/)を見てください。
   </Aside>

8. **ほかの準備を待つ**

   記憶の意味検索のモデルを準備します。日本語で「声で話す」を選んだときは、相槌の種類を判定するモデルと、話し終わりを判定する MaAI も準備します。MaAI は処理が重いので、準備だけしてオフにしておきます。使うときは、設定の「声」の「ターンテイキング(MaAI)」をオンにします。準備できなかったものは、やり直すか、あとに回せます。あとに回したものは、設定の「概要」に出るので、そこで準備します。

   ![ほかの準備が終わった画面](/screens/ja/setup-7-extras.webp)

9. **確かめて始める**

   選んだ内容を見て、「この内容で始める」を押します。

   ![選んだ内容の確認の画面](/screens/ja/setup-8-summary.webp)

</Steps>

始まったら、`MIC OFF` を押して話しかけるか、入力欄に文字を打って送ります。話しかけ方は[使い方](/docs/usage/)にあります。

Agent のジョブを使うなら、続けて [Agent の準備](/docs/start/agent-cli/)に進みます。
