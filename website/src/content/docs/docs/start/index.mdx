## コンピュータ

ASIST は Mac と Windows で動きます。

<Tabs syncKey="os">
<TabItem label="macOS">

Apple Silicon の Mac と、macOS 14 以降が要ります。Intel の Mac では動きません。

声の聞き取りなどのモデルは、この Mac の中で動きます。聞き取りと、読み上げの Irodori-TTS と Qwen3-TTS は、アプリに同梱したプログラムが Mac の GPU で動かします。すべてを使うと、合わせて約 4.2GB のメモリを使います。メモリが 16GB より少ない Mac では聞き取りに小さいモデルを勧めるので、約 2.8GB です。読み上げに Irodori-TTS を選ぶとさらに約 2.0GB、Qwen3-TTS を選ぶと約 1.6GB を使います。この 2 つは、16GB 以上のメモリの Mac で勧めます。内訳は[メモリの目安](/docs/reference/memory/)にあります。

</TabItem>
<TabItem label="Windows">

x64 の CPU の PC と、Windows 11 が要ります。Arm の CPU の Windows には対応していません。

声の聞き取りには、Vulkan のドライバーが認識する単体 GPU または内蔵 GPU を使います。単体 GPU があれば優先し、複数あるときはメモリのいちばん多いものを使います。読み上げの Irodori-TTS と Qwen3-TTS には、引き続き単体 GPU が必要です。

単体 GPU のメモリが 6GB 以上なら、聞き取りに Qwen3-ASR 1.7B を勧めます。それより少なければ、聞き取りに Qwen3-ASR 0.6B を勧めます。内蔵 GPU では自動の聞き取りは Qwen3-ASR 0.6B です。日本語では Haas-ja-v1.0(約 0.66GB)も選べます。読み上げの Irodori-TTS と Qwen3-TTS は、単体 GPU のメモリが 8GB 以上なら勧めます。初回の準備で取得するモデルは、聞き取りが約 0.8〜2.2GB、Irodori-TTS が約 1.9GB、Qwen3-TTS が約 1.2GB です。

使える GPU が無くても、ASIST は使えます。聞き取りにブラウザの中で動く Whisper を使うか、声のエンジンに Gemini Live を選ぶか、文字で話しかけます。

</TabItem>
</Tabs>

## 会話のモデルの API キー

次のどれか 1 つの API キーが要ります。初回セットアップで入れます。料金は、その提供元のアカウントにかかります。

| 提供元 | キーを作るところ |
|---|---|
| Anthropic | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| OpenAI | [platform.openai.com](https://platform.openai.com/api-keys) |
| Google | [aistudio.google.com](https://aistudio.google.com/apikey) |
| Cerebras | [cloud.cerebras.ai](https://cloud.cerebras.ai) |

ChatGPT の Plus か Pro のプランがあれば、API キーの代わりに ChatGPT でログインして使えます。会話の分はプランの使用量に含まれます。くわしくは [ChatGPT のプランで使う](/docs/start/chatgpt/)にあります。

## 入れておくと使えるソフトウェア

| ソフトウェア | 使う機能 |
|---|---|
| `codex` か `claude` の CLI | Agent のジョブと、記憶の整理。使うほうをインストールして、認証を済ませておきます。くわしくは [Agent の準備](/docs/start/agent-cli/)にあります。 |
| VOICEVOX か AivisSpeech | 日本語の読み上げ。Mac では「アプリケーション」に、Windows ではインストール先を変えずに入れておくと、ASIST が裏で起動してつなぎます。ASIST が起動したものは、ASIST を終了するか、読み上げをほかのものに切り替えると止まります。 |

記憶の意味検索、相槌の種類の判定、MaAI が使う Python の環境は、アプリに同梱した uv が作ります。Python もそのときに uv が取得するので、あらかじめ入れておくものはありません。

## 使い始める前に

ASIST の答えは間違っていることがあり、API の料金はあなたのアカウントにかかり、承認した Agent のジョブはあなたのファイルを書き換えることがあります。使い始める前に、[安全に使うために](/docs/privacy/safety/)を読んでください。
