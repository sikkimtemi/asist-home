「会話」で、会話のモデルと、つなぎの一言のモデルを選びます。つなぎの一言は、話している途中に用意して、本回答の前に挟む短い一言です。「声」の「つなぎの一言」をオフにすると、この一言を挟まず、つなぎの一言のモデルも使いません。日本語の会話で、検索やツールに時間がかかるときに入る「ちょっと見てみますね。」のような一言も、オフのあいだは流れません。日本語の会話の相槌は、「相槌」で別にオンとオフを切り替えます。

提供元ごとの API キーは「API キー」のページで保存します。使うモデルの提供元のキーが無いときは、「会話」のモデルの下と「概要」に出ます。保存の前に、その提供元の API でモデルを取得できることを確かめます。キーの無い提供元のモデルは選べません。キーは、Mac ではキーチェーンの鍵で、Windows では Windows のユーザーに結び付いた鍵(DPAPI)で暗号化して保存します。

「ChatGPT」は、API キーの代わりに ChatGPT でのログインで使います。ログインも「API キー」のページの「ChatGPT」の行で行い、会話の分は ChatGPT のプランの使用量に含まれます。くわしくは [ChatGPT のプランで使う](/docs/start/chatgpt/)にあります。

OpenAI と ChatGPT の既定は、会話が GPT-6.1 Terra、つなぎの一言が GPT-6 Luna です。初回セットアップと、モデルの提供元を切り替えたときに使います。保存済みの選択は更新後も維持します。会話には、明快な文章と効率を重視して Terra を、短いつなぎには軽量な Luna を選んでいます。複雑な相談では GPT-6.1 Sol も選べます。ASIST で各モデルの応答時間を比較した結果ではないので、実際の会話で待ち時間と回答を比べて選んでください。

モデルの横で、思考の深さを選べます。既定はいちばん浅い設定です。声で待たせないためで、深くすると、答え始めるまでに十数秒かかることがあります。

Web 検索は提供元の組み込みの検索を使うので、組み込みの検索が無い Cerebras のモデルでは使えません。会話の履歴は提供元に依らない形で保存するので、途中でモデルを変えても会話は続きます。

選べるモデルの一覧は、[使っているモデル](/docs/reference/models/)にあります。
