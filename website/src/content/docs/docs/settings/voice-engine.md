「会話」の「声のエンジン」で、誰が聞いて話すかを選びます。既定は、このコンピュータの音声認識、会話のモデル、読み上げを組み合わせる構成です。

「このコンピュータの音声認識 + 会話モデル + 読み上げ」を選んだときに、音声認識か読み上げがまだ動かなければ、「概要」の「準備が要るもの」と、左の一覧の「声」に出ます。初回の設定で「音声モデルとリアルタイムで話す」か「文字だけで使う」を選んだときは、音声認識と読み上げの準備を飛ばしています。音声認識は、「声」の「音声認識」で「準備する」を押して準備します。準備するまでマイクは使えません。読み上げのエンジンが「読み上げなし(返事は文字だけ)」のときは、返事は文字だけで出ます。声で聞くには、「声」の「読み上げ」でエンジンを選びます。

音声認識のモデルは、「声」の「音声認識」の「モデル」で選びます。Mac の「自動(搭載メモリに合わせる)」と Windows の「自動(GPU のメモリに合わせる)」は、メモリに合わせて Qwen3-ASR の 1.7B か 0.6B を使います。一覧には、会話の言語を聞き取れるモデルだけが、取得する大きさを添えて出ます。日本語なら Haas-ja-v1.0、parakeet-tdt_ctc-0.6b-ja、ReazonSpeech NeMo v2 も、英語、フランス語、ドイツ語、イタリア語、ポルトガル語、スペイン語なら parakeet-tdt-0.6b-v3 も選べます。選んだモデルは、その行の「準備する」で取得します。会話の言語を、選んだモデルが聞き取れない言語に変えると、モデルは自動の選択に戻ります。モデルごとの言語と大きさは[使っているモデル](/docs/reference/models/)に、メモリは[メモリの目安](/docs/reference/memory/)にあります。

Windows の内蔵 GPU でも音声認識を使えます。内蔵 GPU では自動の選択は Qwen3-ASR 0.6B です。Haas を使うには、会話の言語を日本語にし、「モデル」で Haas-ja-v1.0 を選んで「準備する」を押します。取得するファイルは Q8_0 の約 0.66GB です。読み上げには Windows の音声合成、VOICEVOX、AivisSpeech などを選べます。Irodori-TTS と Qwen3-TTS は、Windows では引き続き単体の GPU が必要です。

長く話したときは、音声を無音の部分で 10 秒以下に分けて書き起こし、一つの発話としてつなぎます。無音が無い部分は 10 秒で区切ります。話し終わりや割り込みの判断は変わりません。

Gemini Live を選ぶと、マイクの音声をそのまま Google に送り、Google の声で話します。相槌、聞き取り、話し終わりと割り込みの判定はモデルが行い、このコンピュータの音声認識と読み上げ、つなぎの一言、MaAI は使いません。そのため、単体の GPU が無い Windows でも、声で話せます。エンジン、「モデル」、「声」、「会話が止まってから閉じるまで」のどれかを変えるとマイクがオフになるので、オンにし直します。

Gemini は自分で判断して ASIST のツールを呼びます。実行は ASIST が行うので、書き込みの確認画面はそのまま出ます。会話のモデルは使いません。Google の API キーが要り、料金の目安は音声の入力が 1 分 $0.005、出力が 1 分 $0.018 です。

セッションは話し始めたときに開き、会話が止まって「会話が止まってから閉じるまで」(既定 90 秒)が過ぎると閉じます。閉じているあいだは課金されません。次に話しかけると、直前 3 秒の音声を溜めてから開き直すので、言い始めは欠けません。[見た目](/docs/settings/appearance/)で「画面の上に表示する」をオンにすると、画面の上に、接続、応答までの時間、セッションの分数、料金の見積もりが出ます。マイクをオフにすると、セッションを閉じます。

声は「声」のページで、Google が用意しているものから選びます。「試聴する」で同梱の見本を聞けます。試聴に API は使いません。

Gemini Live では、会話ログに、実際に聞こえた入力と出力の転写を書きます。記憶の整理はこのログから行うので、エンジンを変えても同じ材料で動きます。
